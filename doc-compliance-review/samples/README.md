# 自检样本（`samples/` 顶层文件，随发布包提供）

`samples/` 顶层的七份**输入件**供两类用途（另有一份**输出成品样例**，只作格式对照，见下表末行）：1. `python scripts/smoke-test.py` 装机自检（验证真实文件的提取、脱敏与比对链路）；2. **样例级人工基线**（`scripts/sample-baseline.py`，验证"改完之后审查结论还对不对"）。

| 文件 | 检验链路 | 关键校验 |
|---|---|---|
| `敏感信息示例.docx` | Word → 文本提取 | 提取成功且含合同主体与金额 |
| `扫描件示例.pdf` | 图片型 PDF → pdftoppm → OCR | 无文字层仍能取出可审文本 |
| `图片合同示例.jpg` | 图片 → OCR | 图格式合同可取出可审文本 |
| `合同比对A版.docx` | Word → 文本提取 | 与 B 版配对比对，检出既定差异 |
| `合同比对B版.doc` | 老格式 .doc → LibreOffice → 文本 | 老格式可提取，且与 A 版差异可检出 |
| `制度类示例-员工个人信息保护管理制度.docx` | Word → 文本提取 | 非合同类（内部制度）路径，供基线用例 S4 |
| `格式条款类示例-用户注册须知与免责告知.docx` | Word → 文本提取 | 单方告知＋格式条款路径，供基线用例 S5 |

| `输出成品样例-审查意见报告（格式演示）.md` | 无（不参与自检与基线） | 交付物第 5 类「审查意见报告」的**成品格式对照样例**——供使用者核对"我跑的报告格式对不对"；文件名刻意不含任何输入件主干，不会被 sample-baseline.py 配对 |

**比对样本的差异设置**：A、B 两版为同一份《软件开发服务合同》的前后两稿，B 版相对 A 版共 8 处改动——合同总价 28 万→32 万、开发期限延至 12 月 31 日、付款三期→四期、违约金千分之一→万分之五、验收期 10→15 个工作日、团队不少于三人→两人、删除「排他承诺」条款、新增「知识产权归属」条款并将争议解决由诉讼改为仲裁。

**内容全部虚构**：主体为北京智元科技有限公司 / 示例运维服务有限公司 / 示例办公设备有限公司 / 示例软件技术有限公司 / 示例网络科技有限公司，自然人为张三、李四，身份证号、手机号、银行卡号、统一社会信用代码均为编造，不含任何真实企业与个人信息。请勿将本目录文件用于演示以外的场景。

缺依赖时的表现：Poppler / Tesseract 属可选依赖，缺失时对应两项自检**标记为 SKIP（不计失败）**，补齐依赖后重跑即可。`.doc` 老格式依赖 LibreOffice 转换，缺失时同样 SKIP。

**样本被移除时**（例如只保留提示词版、不跑脚本的场景）：跑 `smoke-test.py` 时上述样本相关项一律标记 SKIP（不计失败），其余项全通过即属正常——总项数保持不变，便于与完整环境报告对齐。
