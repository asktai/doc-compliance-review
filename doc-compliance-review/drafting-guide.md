# 撰写向导（撰写合同 / 撰写合同模板）

> **什么时候读这一份**：使用者输入 **撰写合同 / 起草合同 / 写一份合同 / 撰写模板 / 合同模板**，或在向导入口选了第 5、6 项时才读。**审查链路不加载本文件。**
> **定位**：撰写是**起草**，不是审查。产出的是待谈待定的草案，**须经执业律师复核后方可使用**；写完要审它，请**另起一个任务**走审查链路（同一会话连做易串味）。

## 撰写合同（向导第 5 项）

**先问要素**（一次问完，不挤牙膏）：

```
【撰写合同 · 要素清单】
1.  合同名称与类型（买卖/服务/采购/租赁/承揽/技术开发/保密/劳动…）
2.  当事人（我方全称、对方全称；有无统一社会信用代码/地址/授权代表）
3.  我方身份（甲方/乙方/委托方/服务方…）与谈判地位（强势/均衡/弱势）
4.  标的（名称、规格数量、质量标准、附随文件）
5.  价款与支付（总价、含税与否、预付比例、进度款节点、质保金比例）
6.  履行与交付（时间地点方式、验收标准与期限、不合格处理）
7.  质量保证与售后（保证期、范围、响应时限）
8.  知识产权（背景 IP 归属、成果归属、许可范围）
9.  违约责任（情形、违约金计算口径、上限）
10. 保密与数据（是否涉个人信息 → 走 PIPL 单独同意）
11. 争议解决（管辖法院 或 仲裁机构；法律适用）
12. 期限、变更、解除与终止
13. 交付格式（WORD/MD，默认 WORD）与**审查人名称（必填）**
```

- **未填项按标准立场兜底**（见 SKILL 第八节），并在成稿中标注「【待定：由双方确认】」；**严禁编造**当事人名称、金额、账号、日期、证照号。
- **起草顺序**：先搭骨架（定义→标的→价款→履行→验收→质保→违约→保密→争议→通用条款）→ 再填要素 → 最后做一致性核对（称谓统一、金额数字一致、交叉引用正确，见 SKILL 第六节「修改后复核」）。
- **产出**：按第 3 类「修改后清洁版」出一份无痕迹正文（命名规范见 SKILL 第三节），**并附《要素确认与待定清单》**：已确认项 ／ 按标准立场兜底项 ／ **必须人工确认项**（主体全称与信用代码、金额、账户、管辖、签署日期）。
- **收尾提示（不可省略）**：草案仅作起草辅助，**不构成法律意见**，须经**执业律师复核**；涉资质、特许经营、涉外、劳动、个人信息出境的，须先做专项合规确认。

## 撰写合同模板（向导第 6 项）

面向**反复使用**的场景（标准采购订单、常用服务协议、NDA 等），产出**可复用骨架**而非某一份具体合同：

1. **变量抽成占位符**：当事人、标的、金额、期限、地点一律写成 `{{甲方全称}}`、`{{合同金额}}`，文首列《占位符说明表》（占位符／含义／填写示例／是否必填）。
2. **可选条款单列**：可能有也可能没有的条款（竞业限制、不可抗力细则、审计权、数据出境）放**可选条款区**，注明适用场景与取舍建议，**不混进正文主干**。
3. **关键条款挂批注**：对违约金上限、管辖、责任限制、保密期限等加批注，写明"为什么这样写／谈判时可如何让步"。
4. **附使用须知**：适用边界（适用哪些交易、不适用哪些）、每次使用前必填项、"模板不替代个案审查"。
5. **占位符不得预先填真实主体名与金额**——一旦填实就变成具体合同，须改走「撰写合同」或审查链路。
6. **产出＝第 10 类「模板版」**（见 SKILL 第三节交付物清单）：占位符说明表 ＋ 模板正文 ＋ 可选条款区（逐条挂批注）＋ 使用须知；**谈判地位（见 SKILL 1.6 轴二）在此同样生效**——强势档把对我方有利的写法写进主干、弱势档把不可让步项写死并标注"不得低于此底线"。

> 模板中的**变量口径与可选条款**若与企业内控强相关，建议同步写进私有库（`<ID>@private`），日后用该模板起草的文档即可直接按内控口径审查。
