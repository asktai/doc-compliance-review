# 建筑地产行业包（仅增量/覆盖，引用 core 规则 ID）

覆盖三条业务线：**建设工程**（勘察设计／施工总承包／专业分包／劳务分包／监理）· **商品房**（预售／现售／交付／产权）· **物业**（前期物业／物业服务／公共收益）。

## 常见我方角色
- **施工承包方**（总承包/专业分包/劳务分包）：工程款、签证变更、工期顺延必争；
- **发包方／开发商**：付款节奏与质保金留存、签证管控、免责与风险转移必争；
- **业主／购房人**：交付条件、面积差异、逾期交房与办证违约金、宣传承诺落纸必争；
- **物业服务企业**：服务边界与收费标准、公共收益列支规则、欠费催收程序必争。

## 必备条款焦点
1. **计价与支付**：合同价款形式（固定总价/固定单价/可调价格）明确；进度款挂钩**形象进度或监理确认的已完工程量**；竣工结算期限（收到结算文件后约定期限内核复，逾期视为认可须明示才有此效力）。
2. **签证与变更**：变更以**书面签证**为准，明确估价机制（合同已有单价优先）与工期影响确认流程；口头指令的补签期限。
3. **质量与保修**：质保金比例（**不超过工程价款结算总额 3%**）与返还期限；**缺陷责任期**（一般 1 年、最长不超过 2 年）与**法定保修期**分开写，不得混用。
4. **工期**：开工/竣工日期、顺延事由（设计变更、不可抗力、发包人原因）与确认程序；逾期竣工违约金设上限。
5. **商品房交付**：交付条件为**竣工验收备案**（预售合同须载明）；「两书一表」（住宅质量保证书、住宅使用说明书、分户验收表）齐备；逾期交房与逾期办证违约金分别约定。
6. **物业**：服务事项与标准量化（保洁/秩序/绿化/共用部位维修响应时限）；公共收益**扣除合理成本后归业主**并单独列账公示；物业费调价须经业主共同决定程序。

## 异议期与期限默认（分档）
| 档 | 默认 |
|---|---|
| 建设工程 | **隐蔽工程隐蔽前**通知对方查验（未通知的，对方可要求剥露复验，费用自担）；竣工验收以备案完成为准；数量/外观类异议随验收即时提出，**质量（隐蔽）瑕疵在保修期内随时主张**（V2、V5） |
| 商品房 | 验房交割**外观与配件异议 30 日**；主体结构、防渗漏等质量随**法定最低保修期**（屋面防水、有防水要求的卫生间及外墙面防渗漏 ≥5 年；供热供冷系统 ≥2 个采暖期/供冷期；电气管线、给排水管道、设备安装 ≥2 年；地基基础与主体结构为设计文件规定的合理使用年限） |
| 物业 | 物业费争议随当期核算提出；公共收益公示**每季度**不少于一次 |

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 施工总承包/专业分包 | 施工总承包/专业承包资质等级＋安全生产许可证（Q3、Q4） | 依法必须招标的项目未招标或中标无效的合同效力与结算规则；**禁止转包与违法分包**；垫资条款的利息上限（LPR 口径） |
| 劳务分包 | 劳务企业资质；**不得再分包**（Q7） | 与"劳务派遣/工程转包"划清边界；农民工工资专户与总包代发（欠薪连带责任） |
| 工程监理/勘察设计 | 监理/设计资质（Q3） | 监理权限边界（签认对造价与工期的影响须发包人书面授权）；设计变更的成果文件交付与确认 |
| 工程材料设备采购 | 产品合格证/型式检验 | 与主体合同质保衔接；甲供材的验收交接与保管责任（V1、V3） |
| 商品房预售/现售 | 开发企业资质＋**商品房预售许可证**（Q1、Q2） | 预售资金监管账户；交付条件与两书一表；**面积差异 3% 规则**（绝对值 3% 内据实结算、超出 3% 买受人有权退房，超出部分房价款由出卖人承担或双倍返还依约定不得违反底线）；广告与样板房**具体确定的内容视为要约**（不得以"仅为要约邀请"一概免责） |
| 房屋租赁（开发商持有型） | — | 租赁备案、转租限制、装修残值与恢复原状（T1、V3） |
| 前期物业服务 | 物业服务企业资质核定**已取消**，改信用管理（以现行法规为准） | 前期物业合同期限与业委会选聘衔接；收费启动时点（以交付为准，不得空置期全额预收无依据） |
| 物业服务 | — | 服务标准量化与考核；**不得以停水停电停气催费**；保安消防安全责任划分（L3） |
| 装修装饰（住宅/公装） | 装修资质、消防备案 | 精装修交付标准与样板房一致性、主材品牌型号表附件化（V1）、保修期 |

## 高频风险 TOP
1. 工程进度款与形象进度脱钩、竣工结算"逾期视为认可"未明示（P3、P4）★★★
2. 变更签证无书面确认与估价机制，结算时扯皮 ★★★
3. 质保金比例超 3% 或与缺陷责任期/保修期混写 ★★
4. 转包/违法分包/挂靠（合同无效风险）（Q7）★★★
5. 商品房交付条件写"竣工"而非"竣工验收备案"，两书一表缺失 ★★★
6. 面积差异条款缺失或与 3% 底线规则冲突 ★★
7. 精装修标准笼统（"高档品牌"无型号表）（V1）★★
8. 逾期办证违约金缺失或期限起算点不明 ★★
9. 公共收益归属与公示未约定（依法归业主扣除合理成本）★★
10. 物业费调价未写明业主共同决定程序 ★★

## 对 core 的覆盖
- `P3@realestate`：进度款按**监理确认的形象进度/已完工程量**支付，竣工结算留 3%–5% 尾款待备案与结算核复后支付。
- `V2@realestate`：建设工程质量（隐蔽）瑕疵在**法定保修期**内随时主张；商品房按"两书"载明的最低保修期。
- `Q3@realestate`：资质核验细化为**资质等级匹配工程规模**＋安全生产许可证＋项目班子（建造师）到岗。

## 行业资质
施工总承包/专业承包资质等级须匹配工程规模并持有效安全生产许可证；监理、勘察设计、装饰装修按相应资质；商品房预售须持**预售许可证**；物业服务企业资质核定已取消、以信用与合同约束为主——均以**现行有效法规**为准（引用前按 `core/02-legal-verification-checklist.md` 核验）。

## 标准话术（示例）
- "进度款按监理单位书面确认的形象进度，于每月 __ 日前支付至已完工程价款的 __%；竣工结算以竣工验收备案完成并核复结算文件后 30 日内付清（质保金除外）。"
- "凡涉及增减工程量、材料替换、工期调整的变更，均以经发包人、监理、承包人三方签认的书面签证为准；签证未载明价款的，按合同已有单价或组价规则计取。"
- "质量保证金按工程价款结算总额的 3% 预留，缺陷责任期 24 个月届满后 14 日内无息返还；缺陷责任期不免除承包人按法律法规及本合同承担的保修义务。"
- "该商品房交付条件为取得建设工程竣工验收备案证明，并交付《住宅质量保证书》《住宅使用说明书》；面积差异按绝对值 3% 据实结算，超出 3% 的，买受人有权解除合同。"
- "利用共有部分产生的收益扣除合理成本后归业主共有，物业服务人每季度公示收支明细；未经业主共同决定，不得调整物业服务收费标准。"
