# 建筑地产行业包（仅增量/覆盖，引用 core 规则 ID）

覆盖四条业务线：**土地一级市场**（招拍挂出让／协议出让／一级开发整理／土地转让）· **建设工程**（勘察设计／施工总承包／专业分包／劳务分包／监理）· **商品房**（预售／现售／交付／产权）· **物业**（前期物业／物业服务／公共收益）。

## 常见我方角色
- **受让人／竞得人（拿地方）**：出让公告与合同一致性、出让金支付与逾期后果、净地交付与动工条件、闲置费与收回风险必争；
- **施工承包方**（总承包/专业分包/劳务分包）：工程款、签证变更、工期顺延必争；
- **发包方／开发商**：付款节奏与质保金留存、签证管控、免责与风险转移必争；
- **业主／购房人**：交付条件、面积差异、逾期交房与办证违约金、宣传承诺落纸必争；
- **物业服务企业**：服务边界与收费标准、公共收益列支规则、欠费催收程序必争。

## 必备条款焦点
1. **计价与支付**：合同价款形式（固定总价/固定单价/可调价格）明确；进度款挂钩**形象进度或监理确认的已完工程量**；竣工结算期限（收到结算文件后约定期限内核复，逾期视为认可须明示才有此效力）。
2. **签证与变更**：变更以**书面签证**为准，明确估价机制（合同已有单价优先）与工期影响确认流程；口头指令的补签期限。
3. **质量与保修**：质保金比例（**不超过工程价款结算总额 3%**）与返还期限；**缺陷责任期**（一般 1 年、最长不超过 2 年）与**法定保修期**分开写，不得混用。
4. **工期**：开工/竣工日期、顺延事由（设计变更、不可抗力、发包人原因）与确认程序；逾期竣工违约金设上限。
5. **商品房交付**：交付条件为**竣工验收备案**（含**消防验收**，预售合同须载明）；「两书一表」（住宅质量保证书、住宅使用说明书、分户验收表）齐备；逾期交房与逾期办证违约金分别约定。
6. **物业**：服务事项与标准量化（保洁/秩序/绿化/共用部位维修响应时限）；公共收益**扣除合理成本后归业主**并单独列账公示；物业费调价须经业主共同决定程序。

## 异议期与期限默认（分档）
| 档 | 默认 |
|---|---|
| 土地出让 | 出让金**首付不低于 50%、一年内缴清**（按出让公告与现行政策核验）；竞得后按公告/成交确认书载明期限内签订出让合同；**动工期限**自交付之日起算（约定具体日期或"自交付之日起 __ 个月内"），因政府原因未按期动工的顺延且**不计征闲置费** |
| 建设工程 | **隐蔽工程隐蔽前**通知对方查验（未通知的，对方可要求剥露复验，费用自担）；竣工验收以备案完成为准；数量/外观类异议随验收即时提出，**质量（隐蔽）瑕疵在保修期内随时主张**（V2、V5） |
| 商品房 | 验房交割**外观与配件异议 30 日**；主体结构、防渗漏等质量随**法定最低保修期**（屋面防水、有防水要求的卫生间及外墙面防渗漏 ≥5 年；供热供冷系统 ≥2 个采暖期/供冷期；电气管线、给排水管道、设备安装 ≥2 年；地基基础与主体结构为设计文件规定的合理使用年限） |
| 物业 | 物业费争议随当期核算提出；公共收益公示**每季度**不少于一次 |

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 土地出让（招拍挂/协议） | 竞买人资格按公告；经营性用地（商业/旅游/娱乐/商品住宅）**必须招拍挂**（Q1、J1） | **出让公告→成交确认书→出让合同三文件一致性**（规划条件、出让金、交付条件不得相互矛盾）；出让合同一方为自然资源主管部门，性质与管辖按合同约定审查；竞得后拒签合同的保证金处理须有依据；**出让金支付节点**（首付比例与缴清期限）与逾期利息、收回后果对等；**净地交付**（权利清晰、无抵押/查封/租赁负担、征地补偿安置落实、具备动工条件）；规划条件（容积率）变更的补缴差价机制；动工期限与**闲置费/无偿收回**触发条件（政府原因顺延不计征） |
| 土地一级开发整理 | 委托方主体（政府/平台公司）授权 | 投资回报与**收益分成的合规性**（不得与土地出让收入直接挂钩的约定按现行政策核验）；移交验收标准与审计；拆迁补偿责任边界（T2、L5） |
| 土地转让（二级市场） | 权属证书；**未按出让合同完成开发投资不得转让**（以现行法规为准） | 转让条件与在建工程抵押/查封负担披露；划拨地转让的批准与补缴出让金；地上一并转让的租赁负担（E、Q） |
| 施工总承包/专业分包 | 施工总承包/专业承包资质等级＋安全生产许可证（Q3、Q4） | 依法必须招标的项目未招标或中标无效的合同效力与结算规则；**禁止转包与违法分包**；垫资条款的利息上限（LPR 口径）；**报建报批手续**（规划许可、施工许可等）的办理责任、期限与费用划分——未取得施工许可不得开工，因一方迟延办理致停工窝工的由责任方承担 |
| 劳务分包 | 劳务企业资质；**不得再分包**（Q7） | 与"劳务派遣/工程转包"划清边界；农民工工资专户与总包代发（欠薪连带责任） |
| 劳务用工/农民工工资 | 劳务分包资质；用工实名制 | **工资专用账户＋总承包单位代发**；分包单位拖欠的由**总承包单位先行清偿**再追偿（"兜底"，依保障农民工工资支付相关法规，条号核验）；"劳务/雇佣"与劳动关系定性影响责任路径（劳动关系→劳动法，劳务关系→民法典）；转包/违法分包情形下的**穿透式**清偿责任 |
| 房屋租赁/出租屋 | 租赁备案（按属地核验） | **维修责任默认划分**（出租人维修义务，当事人可另行约定；承租人原因损坏由承租人担责）；**买卖不破租赁**（占有期限内所有权变动不影响租赁，受让人承继权利义务）；转租须经出租人同意；装饰装修残值与恢复原状（T1、V3）；出租屋安全与消防责任 |
| 工程监理/勘察设计 | 监理/设计资质（Q3） | 监理权限边界（签认对造价与工期的影响须发包人书面授权）；设计变更的成果文件交付与确认 |
| 工程材料设备采购 | 产品合格证/型式检验 | 与主体合同质保衔接；甲供材的验收交接与保管责任（V1、V3） |
| 商品房预售/现售 | 开发企业资质＋**商品房预售许可证**（Q1、Q2） | 预售资金监管账户；交付条件与两书一表；**面积差异 3% 规则**（绝对值 3% 内据实结算、超出 3% 买受人有权退房，超出部分房价款由出卖人承担或双倍返还依约定不得违反底线）；广告与样板房**具体确定的内容视为要约**（不得以"仅为要约邀请"一概免责） |
| 房屋租赁（开发商持有型） | — | 租赁备案、转租限制、装修残值与恢复原状（T1、V3）；所有权变动时向受让人交待**买卖不破租赁**与租金收取权衔接 |
| 商业/工业物业租赁（商铺/写字楼/厂房） | 经营性用房租赁备案；涉消防改造的消防审批 | **免租期/装修期**与起租、租金起算衔接；租金递增与调价机制；**用途与业态限制**（不得擅自改变约定用途，违约后果明确）；经营证照办理中出租人的**配合义务**（产权证明、租赁备案凭证等）；**消防与安全责任划分**（改造报批、验收合格后方可投入使用）；商业水电、物业费承担口径 |
| 不动产抵押与按揭融资 | 抵押登记；预售资金监管 | 转让已抵押不动产的**抵押权人同意与价款清偿**安排；出卖人**隐瞒抵押/查封**权利负担的买受人解除权与赔偿（E）；按揭贷款未获批且**不可归责双方**的合同解除与已付款返还；**在建工程抵押**与预售资金监管账户的衔接（P1） |
| 房屋权属变动（继承/转移/共有） | 权属证书；继承按民法典继承编与不动产登记规则 | **转移登记期限**与税费承担约定；继承情形的共有人确认与登记程序提示（审查要点，不代拟继承安排）；**共有房产处分须经共有人同意**（按份共有经占份额三分之二以上共有人或全体共同共有人同意，以现行民法典为准）；**共有产权房等政策性住房**的转让限制、回购与上市条件按当地政策核验；一房数卖与预告登记提示 |
| 前期物业服务 | 物业服务企业资质核定**已取消**，改信用管理（以现行法规为准） | 前期物业合同期限与业委会选聘衔接；收费启动时点（以交付为准，不得空置期全额预收无依据） |
| 物业服务 | — | 服务标准量化与考核；**不得以停水停电停气催费**；保安消防安全责任划分（L3） |
| 装修装饰（住宅/公装） | 装修资质、消防备案 | 精装修交付标准与样板房一致性、主材品牌型号表附件化（V1）、保修期 |

## 高频风险 TOP
1. 出让公告、成交确认书与出让合同三文件不一致（规划条件/出让金/交付口径）★★★
2. 出让金支付节点与逾期后果不对等（滞纳金畸高、直接收回无催告宽限）（P1、P2）★★★
3. **闲置土地**：动工期限不明、政府原因与受让人原因未区分、闲置费与无偿收回触发条件照搬法规原文却无程序保障 ★★★
4. 毛地/非净地出让：征地补偿安置未落实、地上抵押查封负担未披露（E、G8）★★★
5. 一级开发收益分成与土地出让收入挂钩的合规性风险 ★★★
6. 工程进度款与形象进度脱钩、竣工结算"逾期视为认可"未明示（P3、P4）★★★
7. 变更签证无书面确认与估价机制，结算时扯皮 ★★★
8. 转包/违法分包/挂靠（合同无效风险）（Q7）★★★
9. 商品房交付条件写"竣工"而非"竣工验收备案"，两书一表缺失 ★★★
10. 质保金比例超 3% 或与缺陷责任期/保修期混写 ★★
11. 面积差异条款缺失或与 3% 底线规则冲突 ★★
12. 精装修标准笼统（"高档品牌"无型号表）（V1）★★
13. 逾期办证违约金缺失或期限起算点不明 ★★
14. 公共收益归属与公示未约定（依法归业主扣除合理成本）★★
15. 物业费调价未写明业主共同决定程序 ★★
16. 农民工工资支付责任缺失或与"总包代发＋先行清偿"法定要求冲突（转包/违法分包下的穿透式清偿）★★★
17. 租赁期内所有权变动未交待买卖不破租赁、维修责任主体不明 ★★
18. 报建报批手续办理责任与费用未划分，停工窝工损失无归口 ★★
19. 商业/工业物业租赁免租期与用途限制缺失、消防改造报批与安全责任划分不明 ★★
20. 出卖人未披露房屋已抵押/查封等权利负担，或按揭贷款未获批的解除与退款机制缺失 ★★★

## 对 core 的覆盖
- `P3@realestate`：进度款按**监理确认的形象进度/已完工程量**支付，竣工结算留 3%–5% 尾款待备案与结算核复后支付。
- `V2@realestate`：建设工程质量（隐蔽）瑕疵在**法定保修期**内随时主张；商品房按"两书"载明的最低保修期。
- `Q3@realestate`：资质核验细化为**资质等级匹配工程规模**＋安全生产许可证＋项目班子（建造师）到岗。

## 行业资质
施工总承包/专业承包资质等级须匹配工程规模并持有效安全生产许可证；监理、勘察设计、装饰装修按相应资质；商品房预售须持**预售许可证**；物业服务企业资质核定已取消、以信用与合同约束为主——均以**现行有效法规**为准（引用前按 `core/02-legal-verification-checklist.md` 核验）。

## 标准话术（示例）
- "出让宗地以现状（净地）交付：宗地权利清晰、无抵押、查封或其他权利负担，征地拆迁补偿安置已落实完毕；出让人保证受让人按出让合同约定动工期限内具备动工开发条件。"
- "因不可抗力、政府原因或出让人原因致使宗地未能按期动工的，动工期限相应顺延，期间不计征土地闲置费，出让人应书面确认顺延事由与期限。"
- "分包单位拖欠农民工工资的，由总承包单位先行清偿，再依法向分包单位追偿；农民工工资通过农民工工资专用账户，由总承包单位按实名制考勤按月代发。"
- "租赁期间除承租人原因造成的损坏外，租赁物维修义务由出租人承担；出租人经催告后合理期限内不维修的，承租人可自行维修，费用由出租人负担。"
- "租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响本租赁合同的效力；受让人承继出租人在本合同项下的权利义务，租金收取权自所有权转移之日起由受让人行使。"
- "报建、报批等行政手续由【责任方】在约定期限内办理并承担费用；因未及时办理导致无法开工或停工窝工的，工期相应顺延，损失由责任方承担。"
- "进度款按监理单位书面确认的形象进度，于每月 __ 日前支付至已完工程价款的 __%；竣工结算以竣工验收备案完成并核复结算文件后 30 日内付清（质保金除外）。"
- "凡涉及增减工程量、材料替换、工期调整的变更，均以经发包人、监理、承包人三方签认的书面签证为准；签证未载明价款的，按合同已有单价或组价规则计取。"
- "质量保证金按工程价款结算总额的 3% 预留，缺陷责任期 24 个月届满后 14 日内无息返还；缺陷责任期不免除承包人按法律法规及本合同承担的保修义务。"
- "该商品房交付条件为取得建设工程竣工验收备案证明，并交付《住宅质量保证书》《住宅使用说明书》；面积差异按绝对值 3% 据实结算，超出 3% 的，买受人有权解除合同。"
- "利用共有部分产生的收益扣除合理成本后归业主共有，物业服务人每季度公示收支明细；未经业主共同决定，不得调整物业服务收费标准。"
- "承租人不得擅自改变房屋约定用途；装修涉及消防改造的，须依法报批并经出租人书面同意，经验收合格后方可投入使用；出租人应为承租人办理经营证照提供产权证明等必要配合文件。"
- "出卖人保证该房屋不存在抵押、查封或其他权利负担；因隐瞒抵押致无法办理转移登记的，买受人有权解除合同并要求赔偿损失。买受人按揭贷款未获批且不可归责于双方的，双方均可解除合同，出卖人应返还已收购房款。"
