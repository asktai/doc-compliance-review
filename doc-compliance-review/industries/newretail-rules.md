# 新零售行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
品牌方／渠道方（经销商、代运营、平台）。

> **达人带货链路先分清四方，责任随角色变**。**品牌方/商家**（商品与价格提供者，对商品质量与宣传内容真实性负责）、**平台/直播间运营者**（提供场所与技术服务，对入驻资质、内容与交易秩序负法定责任）、**MCN/服务机构**（招募、管理、培训达人并对接商务，对履约与账号行为负管理责任）、**达人/主播/流量端**（直播间讲解的人，以自己名义推荐时可能被认定为广告代言人，见《互联网广告管理办法》）。同一份合同里我方可能兼具两角，或名义是"内容合作"实为带货分成，**责任按实质认定，不因换个称呼就绕开**。
>
> 内容侧（广告审查、广告发布登记、直播物料的下架与代言责任）已由**新媒体行业包**系统覆盖；本包聚焦**交易侧**——钱怎么算、货怎么退、价怎么定、流量数据谁负责。

## 必备条款焦点
1. 价格与渠道：产品清单/供货价/建议零售价附件化并盖章；授权渠道枚举（越界即违约）。
2. 预付款与担保：预付比例、保证金/诚意金、担保方式（G组）。
3. 排他边界：附业绩前提与退出回收机制。
4. 任务与返利：返利基数以回款与对账单为准；超额是否结转明确。
5. 调价机制：单一、可单方行使、通知即生效。
6. 退换货：非质量不退；滞销/近效期退货附条件（比例/时限）。
7. 数据：消费者个人信息受托处理（D2）；三流一致（E6）。
8. **带货合作的交易口径**：坑位费、佣金（抽成/抽佣）与退款后的佣金扣回，**三件事在一张表里对齐**（见"结算与费用"）。
9. **GMV 与考核口径**：带货合同必写"钱算到哪一步"（下单/支付/核销/退货剔除），否则结算争议必发（V1、V3）。
10. **账号与店铺资产**：谁持有账号、谁掌控后台权限、终止后怎么交接（I2、T4）。
11. **退出与善后**：取消、终止、退出、退款、不可抗力、违约、处罚七项机制必须成套，且**善后清算要有顺序**（见"退出、终止与善后机制"）。
12. **个人主播的签约路径**：先确认是"与经销商直签"还是"与机构签约"，两条路径在**关系性质、结算链路、账号归属**上完全不同（见"个人主播的两条合作路径"）。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 电商平台服务 | 平台资质备案 | 平台责任与商家审核、信息披露（《电子商务法》）、服务费与结算 |
| 供应商直供 | 供应商资质 | 结算账期与扣点、退换货、质量与索赔（P2、L3） |
| 社区团购/前置仓 | 经营资质 | 团长/自提点责任、生鲜损耗与退赔、配送时效 |
| **达人/网红带货（含 KOL、KOC、KOS、素人达人）** | 达人身份与资质、服务机构主体 | **合作性质（服务 vs 分销）**、坑位费与佣金结构、退货后佣金扣回、GMV 口径（V1、V3） |
| **MCN/主播机构服务** | 机构主体与达人管理关系 | 旗下达人履约的组织者责任、达人擅自接单的违约、账户与结算双主体一致性（E6、E2） |
| **店铺入驻/代运营/代播** | 平台入驻资质、账号实名 | 账号权属与后台权限、**代持风险**、KPI/ROI 考核、保证金与扣罚（M1、V1） |
| **个人主播×直接经销商** | 个人身份与税务、供货方资质 | 服务性质界定、代扣代缴与完税凭证、履约担保（保证人或保证金）、**售后由经销商承担**（E6、L3） |
| **个人主播×机构（MCN）** | 机构主体与达人管理关系 | **关系性质**（劳务/劳动/合作，看管理从属性）、结算链路分层、账号与粉丝归属、肖像单独授权（E6、I2） |
| **私域/社群/小程序商城** | ICP 备案或许可、支付与经营者主体 | 个人信息受托处理（D2）、诱导分享拉新合规、不得擅自向站外导流（平台规则） |
| 跨境保税/直播带货 | 海关注册、平台资质 | 保税/直邮模式、税费与退换、知产与合规 |
| 加盟/连锁 | 商业特许经营备案 | 信息披露（《商业特许经营管理条例》）、区域保护、退出机制 |
| O2O 即时零售 | 合作方资质 | 履约时效与超时赔付、平台规则变更 |
| 跨境电商 | 海关注册 | 保税/直邮模式、税费与退换、知产与合规 |

> 通用：**转售价格维持（RPM）反垄断风险**（《反垄断法》）、渠道价格体系合规、数据与个人信息（D）、管辖（J1）。

## 达人类型与合作条款差异（先看是哪一类人，再谈条款）

| 类型 | 说人话 | 合作方式与付款 | 条款重点 |
|---|---|---|---|
| **KOL**（关键意见领袖） | 有大粉量的头部达人，负责引爆认知 | 坑位费 + 佣金（CPS）；多为一口价 | 独家/排他期、竞品清单、**名誉条款**、内容修改与终审权 |
| **KOC**（关键意见消费者） | 粉丝量不大但真实、能带动身边人购买 | 纯佣为主，或小额样品+佣金 | 多为批量合作 → **争议集中在结算账单口径**通常为非排他，可同时为多个品牌带货 |
| **KOS**（关键意见销售） | 具备销售身份或专业资质的人（导购、柜员、经纪顾问、医师类等） | 底薪+提成或佣金 | 是否兼具职务行为 → 明确**所属单位的关系**、劳务/劳动关系界定、不得利用职务便利引流 |
| **素人达人** | 无粉丝基础，靠内容自然流量出单 | 纯佣、样品置换 | 数量与投放频次约定、**不得为凑数刷单**、数据真实性承诺 |
| **明星/艺人代言** | 有公众人物属性的代言人 | 高额代言费 + 代言期限 + 后续权利 | 使用承诺（《广告法》第 38 条）、**道德条款**、肖像/姓名授权范围与期限（I2） |
| **机构/主播（MCN 派遣）** | 机构派人直播，人不是合同主体 | 服务费结算给机构 | **主体错配**：接单主体、收款主体、开票主体须一致（E6）；达人本人须签署承诺书或加入连带保证（G） |

> **合伙人 vs 服务者**：达人既拿服务费又对销售结果分成时，容易被当作"合作关系"而非"服务关系"。合同里须明确**性质**（服务/推广/分销/居间），因为性质决定了责任边界、税票与能不能主张最低保障。

## 结算与费用（钱怎么算，最容易扯皮）

| 费用项 | 含义与常见写法 | 审查要点 |
|---|---|---|
| **坑位费** | 占一个直播时段/坑位的固定服务费 | **必须与"是否保 GMV/保 ROI"绑定写清**：保量不达标按什么比例退还、延播还是退款，退了还收不收后续佣金（P1、V1） |
| **佣金/抽成/抽佣** | 按成交额比例分成 | 写明基数（实付金额是否含运费、税费、优惠分摊）、券后核定规则、**退款即扣回**（已付佣金从下次结算或保证金扣） |
| **纯佣模式** | 不收固定服务费，全部按成交额结算 | 风险在"刷单凑 GMV"与"退货集中退款" → 约定**佣金按签收并过退货期后结算**、设置退货率异常条款 |
| **GMV 口径** | 拍下金额总和，含未付、含退货 | 必须定义为**支付金额/结算金额**，并排除：取消订单、退货退款、刷单、优惠券成本分摊；以平台后台数据为准并保留**对账与审计权**（D1） |
| **ROI / 转化率** | 投入产出比、订单转化率 | 考核前须约定**口径与数据源**（谁的平台后台、可否第三方监测、抽样核销），单方数据不得作为唯一结算依据 |
| **引流款/福利款/利润款/战略款** | 不同角色商品：引流款用来拉流量、福利款做秒杀、利润款扛毛利、战略款做长期心智 | 逐款写**最低售价/最低折扣底线**与库存、供货优先顺序；并明确福利款的亏损由谁承担、是否计入投入成本 |

> **账实一致是硬要求**：佣金、坑位费、返现、返佣一律如实入账，**不得账外支付或个人卡过账**（《反不正当竞争法》第 8 条商业贿赂，H 组）。

## 价格、促销与宣传口径

| 情形 | 依据 | 审查要点 |
|---|---|---|
| "全网最低价""全网最低""史上最低" | 《广告法》第 9 条绝对化用语 | 无法相对证明的"最低"属违规 → 改写为"本活动期间本店最低价"并写明对比范围与时点 |
| "跳楼价""血拼价""地板价"等夸张定价 | 明码标价与价格标示要求（现行规定） | 属煽动性价格宣传；核实**原价来源**（不得虚构原价、虚构降价幅度），《明码标价和禁止价格欺诈规定》 |
| 比价/降价补差条款 | 合同义务 vs 价格承诺 | 约定"同一期间同规格同渠道若低于本约定价的据实补差"，但**平台/渠道的最低售价约束要防 RPM**（《反垄断法》纵向协议） |
| 违禁词/极限词（国家级、最高级、第一、最佳、根治、100% 有效等） | 《广告法》第 9 条、《互联网广告管理办法》 | 直播口播更易踩线 → 附**禁用词清单**作为合同附件，违者计违约金并立即下架（T4、P2） |
| 功效/疗效宣称（普通食品宣称治病、化妆品宣称医美效果） | 《广告法》相应条款 | 非特殊品类不得宣称治疗功效；保健食品须遵守"不是药物"提示 |
| 出口/跨境产品的中文标示与说明 | 现行产品责任与标签规定 | 中文标签、成分表、原产国、进口手续齐备 |

> **"最低价"是两层问题**：对外宣传层面是无依据宣传（行政违法风险）；对内协议层面若同时要求渠道"不低于某价"，则可能构成**转售价格维持**（反垄断风险）。两个层面都要拦。

## 流量、数据与私域合规

| 情形 | 说明 | 审查要点 |
|---|---|---|
| **NPC/水军/带节奏** | 由团队操作的辅助账号营造抢购氛围、带评论节奏 | 属**虚构交易与人气操纵**：不得虚构关注度、浏览量、点赞量与交易额（《网络直播营销管理办法（试行）》），并构成虚假宣传 → 明令禁止并设高额违约金与解除权（D1、L3） |
| **挂榜/定榜/偷塔** | 打赏排行榜上的占位、冲榜保名次、临结算反超等玩法 | 涉及**打赏资金性质**（赠与/服务消费）、未成年人打赏退款、活动规则公示与举证 → 活动规则须事先公示、设立退款与异常通道 |
| **甩人/切流量** | 把平台的流量导到站外（或个人号/社群）成交，规避平台扣点 | 通常**违反平台入驻协议**，并可能构成不正当竞争或违约 → 约定"成交必须在约定渠道完成"，发现站外成交按约定倍数扣罚 |
| **私域运营** | 社群、企微、朋友圈、小程序商城沉淀用户 | 个人信息处理须有合法基础、告知同意、受托处理边界（D2）；不得非法获取、泄露或过度营销 |
| **刷量/虚假流量** | 买播放、买粉、买评论、虚假交易 | 数据造假即时解除＋退费＋赔偿（V3、L3、P2） |
| **代运营/代持账号** | 店铺或账号由他人注册、由乙方实际操作 | **代持风险**：账号实名主体与实际经营人分离，责任落到登记主体 → 须书面确认登记主体、签署代持承诺、约定违规损失归属与配合过户义务（E2、E6） |
| **投流账户**（巨量千川/巨量引擎等广告投放账户） | 用于买流量的广告账户，充值后按消耗扣费 | 写明**账户以谁的主体注册、由谁实名**（权属与过户义务）、充值款性质与**余额退还**、消耗明细须与平台后台逐日核对并可导出（D1）；受托投放须书面授权，不得擅自变更预算与投放计划；**充值主体、投放主体与开票主体须一致**（E6、H） |
| 平台数据权限与回传 | 数据看板、会员数据、订单明细的获取 | 明确数据范围、回传频率、是否导出留存；涉及个人信息的须匿名化/去标识化（D1、D2） |

> **依据速查**：《互联网信息服务管理办法》（经营性互联网信息服务**许可**、非经营性**备案**；内容"九不准"）、《网络数据安全管理条例》（数据处理活动的分类分级安全义务，涉个人信息与重要数据的按规定处理）、《个人信息保护法》、《电子商务法》（平台不得删除消费者评价、不得虚构交易或编造用户评价，见第 17 条、第 39 条）。具体条号以现行法规为准。

## 内容安全、代言与明星风险

| 情形 | 条款该怎么放 |
|---|---|
| **不当言论/不当行为**（含在网络空间发表的言论） | 设定**言论红线**：不得发表违背公序良俗、损害我方商誉、违反法律法规的内容；违反即得**解除 + 退费 + 赔偿**（T4、L3） |
| **涉宗教、政治言论** | 直播间与商品宣传**不得涉及国家象征、民族宗教歧视、政治议题**；违反的立即停播下架并追责（内容"九不准"，《互联网信息服务管理办法》） |
| **艺人失德／达人失德（道德条款）** | 明确"失德"的列举范围（刑事处罚、行政处罚、自陈不利事实、舆论重大负面），赋予**单方解约权、费用退还、物料下架义务与违约金**；违约金应设**封顶**（P2）避免被认定畸高 |
| **明星代言／达人代言** | 须已实际使用商品或接受过服务（《广告法》第 38 条）；**受行政处罚未满三年**的不得作为代言人；未成年人（十周岁以下）不得作广告代言（同上） |
| **肖像/姓名/形象授权** | 范围（品类/渠道/地域）、期限、可否二次剪辑与投流；到期后的**下架期**（一般 15–30 日）与素材销毁（I2、T4） |
| **未成年人保护** | 直播营销人员年龄与未成年人打赏退款；《未成年人保护法》相关规定 → 明确不得诱导未成年人大额消费，并配合退款义务 |

## 平台入驻、店铺运营与代运营考核

1. **入驻**：核验平台方与我方经营者双证照、品牌授权链完整；品类保证金、技术服务费率、**活动参与义务**逐项写实。
2. **店铺资产**：店铺主体、账号实名、经营密码与子账号权限登记；停/转/关店的权利归属（I2、T4）。
3. **KPI 与考核**：明确周期（月/季）、指标定义（GMV、ROI、转化率、退款率、上新数）、数据源与举证方；不达标的处理是**整改 → 降级服务费 → 续约否决**，不得一步到位扣光保证金。
4. **保证金扣罚**：须写明扣罚情形、金额上限、书面通知与申辩渠道；**不得概括授权平台单方扣罚**（M1、P2）。
5. **平台规则变更**：平台不得单方变更费率、结算周期或规则；确需变更须**提前书面通知**，未接受的可无责终止并退还保证金余额。
6. **自营与竞价**：平台自营须显著标明"自营"；竞价排名商品须显著标明"广告"（《电子商务法》相应条款）。

## 退出、终止与善后机制（七项必写）

| 机制 | 条款该怎么写 | 审查要点（core 引用） |
|---|---|---|
| **合作取消** | 区分「取消单场」与「取消合作」；写明通知方式、生效时点、无责取消的窗口期 | 窗口期外取消按违约处理；已发生成本（备货、场次预留、物料）须凭**书面凭证**结算，不得只写"据实分摊"而不给凭证要求（P1、V1） |
| **协议终止机制** | 事由分类：期满／协商／单方（不附理由须付补偿）／违约解除／法定解除；通知期与生效日 | 终止不当然处理**在途订单与已售货品**，须单独写；**存续条款**（保密、结算、知产、争议解决、数据删除）须明确"终止后仍有效"（T4、J1） |
| **退出机制** | 达人／主播／渠道／店铺退出时的权限与账号回收、保证金退还、库存退货、粉丝与客户资源归属、竞业 | 退出不等于解约即了事：**交接清单与时限**、保证金退还条件（无未结争议与未决售后）、退出后不得再使用品牌资产（I2、T4） |
| **退款机制** | 退款情形（质量瑕疵／描述不符／物流破损／七日无理由）、申请流程、审核时限、责任划分 | 写明**谁先行垫付**、平台先行赔付后的**追偿路径**；退款与佣金·坑位费的联动（佣金扣回）；举证责任与争议期（P1、V3） |
| **不可抗力与善后** | 范围（自然灾害、疫情、政府行为、平台封禁、政策变动）、通知与举证义务、免责范围、持续时长触发解除 | 不可抗力只**免除受影响的履行义务**，不当然免除已发生的付款义务；须约定**善后清算顺序**：已投放费用 → 已售货品与售后退换 → 未结佣金 → 库存与物料处理。**平台限流、规则突变、断供**建议单列为「重大不利变化」另行约定解除权（T4、P1） |
| **违约机制** | 违约情形清单 ＋ 责任形态（继续履行／补救／违约金／赔偿／解除）＋ 宽限期与补救机会 | 违约金须与实际损失挂钩并**设封顶**；给一次**书面补救机会**再行使解除权，避免轻微违约即触发解约；约定通知与举证程序（L3、P2） |
| **处罚机制** | 平台／品牌方对达人、店铺的处罚（扣保证金／降权／下线／清退） | **四要件须齐**：情形、幅度、上限、程序（通知—申辩—复核）；内部处罚不替代法定责任；不得概括授权单方扣罚（M1、P2） |

## 个人主播的两条合作路径

| 维度 | 与直接经销商合作 | 与机构（MCN）合作／雇佣 |
|---|---|---|
| 合同主体 | 主播个人 ↔ 经销商·品牌方 | 主播 ↔ 机构；机构再与品牌方签约，或签三方协议 |
| 关系性质 | 多为**服务／推广合同**（个人为独立主体） | 须辨明**劳务／劳动／合作**：机构对主播有无排班、考核、纪律管理，决定性质——**管理从属性越强，越可能被认定为劳动关系**（连带社保与工伤责任） |
| 结算链路 | 直接结算给个人：**代扣代缴个人所得税**、发票与完税凭证 | 品牌 → 机构 → 主播：**每层的结算依据、开票主体、扣税主体**须逐一写清，防止链条断裂后主播直接向品牌方主张付款（E6） |
| 账号与粉丝 | 账号归主播 ⇒ 约定使用范围、合作期内不得变更、终止后内容下架 | 账号多由机构掌控 ⇒ 主播须保留个人身份与必要数据权益，明确解约后粉丝与内容归属 |
| 独家与竞业 | 一般不做强排他 | 机构常要求独家：须有**期限、范围与补偿**，否则难以执行 |
| 履约与售后 | 个人履约能力弱 ⇒ 设**连带保证人或保证金**；售后与消费者投诉由经销商承担 | 机构对旗下达人行为负**管理责任**；售后按三方约定，但**最终由货主承担** |
| 肖像与素材 | 肖像授权范围、期限、到期下架期（I2） | 机构打包授权时须确认**已取得主播单独书面同意**，否则授权链断裂 |
| 个人信息 | 身份证、银行账户、手机号按个人信息处理，最小必要并加密，不写入公开文案（D2） | 同上；机构汇总数据须有合法性基础与用途限制 |

> **共同红线**：无论走哪条路径，**货权、质量与售后责任始终由供货方承担**；主播／达人的责任限于**宣传内容的真实性**（口播、脚本、展示）。合同里若出现"主播对商品质量与售后承担一切责任"，属**责任错配**，应改回按角色分责（L3、Q1）。

## 推广与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 广告/推广 | 广告用语合规（禁用绝对化用语，《广告法》第 9 条）、促销规则与价格标示、赠品与返现合规 |
| 直播/达人带货 | 主播以自身名义作推荐构成**广告代言**的责任、禁用词清单、GMV 与佣金口径、退货后佣金扣回 |
| 达人/MCN 合作 | 合作性质、账号权属、达人管理与组织者责任、**收款主体与开票一致**（E6） |
| 渠道/价格 | **RPM 转售价格维持反垄断风险**、最低售价条款改写为"建议价/补差"、窜货管控 |
| 流量/数据 | 禁刷量与虚假人气、NPC/水军禁止、私域导流限制、数据与个人信息（D1、D2） |
| 佣金/服务商 | 佣金与促销费用如实入账、禁商业贿赂（《反不正当竞争法》第 8 条）、服务商资质 |
| 电商/终端 | 平台信息披露（《电子商务法》）、七日无理由退货、平台责任与入驻规则变更、数据与个人信息（D） |

## 高频风险 TOP
1. 附件留空、价格/产品清单缺失（V1、P1）★★★
2. 排他过宽、无退出机制 ★★
3. 转售价格维持(RPM)反垄断风险（《反垄断法》第18条）★★
4. 无条件滞销退货、集采补差无边界 ★★
5. 违约金畸高（P2）★★★
6. **GMV/考核口径未定义，结算全凭对方后台数据**（V1、V3、D1）★★★
7. **退款后佣金不扣回、坑位费保量未约定退还**（M1、P1）★★★
8. 主体错配：接单/收款/开票不一致，达人个人未代扣代缴（E6、E2）★★
9. **虚构交易或流量造假（含 NPC、水军、买播放）**（虚假宣传，L3）★★★
10. **无依据的"全网最低价""史低"等极限定价宣传**（《广告法》第 9 条、价格欺诈规定）★★
11. **缺道德条款与失德解约机制**（明星/头部达人合作）★★
12. **账号代持、店铺实名主体与实际经营人分离**（T4、E2）★★
13. 平台规则变更单方生效、保证金概括扣罚权（M1、P2）★★
14. **投流账户权属与充值消耗无据可核**（巨量千川/巨量引擎类账户；账户户名、余额退还、消耗明细缺失）★★
15. **只有"可解除"没有善后清算**：终止后货、款、佣金、物料、账号权限无处理顺序（T4、P1）★★★
16. **不可抗力条款一揽子免责**：把平台限流、规则突变、断供都写进不可抗力并免除已付义务（T4、L3）★★
17. **个人主播与机构关系性质不清**：名为合作实为劳动管理，触发社保与工伤责任（E2、E6）★★
18. **主播被要求对商品质量与售后承担一切责任**（责任错配，应由供货方承担）（L3、Q1）★★★

## 对 core 的覆盖
- `M1@newretail`：明确"保证金"性质（非定金/非罚则），并限制平台单方扣罚（须列明情形、上限与申辩渠道）。
- `J1@newretail`：管辖首选品牌方所在地。
- `I2@newretail`：定制成果 IP 归品牌方；店铺/账号实名登记权益一并归属登记主体，代持须书面确认。
- `V1@newretail`：GMV、ROI、转化率等考核指标须**定义口径与数据源**（回调/核销/退货剔除规则），单方后台数据不得作为唯一结算依据，须保留对账异议权与第三方核销权。
- `V3@newretail`：达人与机构应提供可被核验的投放与交易凭证（下单编号、结算明细、退票记录），平台后台数据不得篡改。
- `P1@newretail`：坑位费与保量挂钩，未达约定 GMV/ROI 按比例退还或经书面确认后延播补足；退款或退单的，已结佣金在下次结算款中扣回；**提前取消合作按窗口期与已发生成本的书面凭证结算**；不可抗力善后**不豁免已发生的付款义务**。
- `L3@newretail`：因虚假宣传、违法广告、NPC 或流量造假导致的行政罚款、平台处罚与对外赔付，由**过错方**承担；我方先行承担的就对方过错部分**全额追偿**，并有权暂停结算直至争议解决。**责任错配须纠正**：让主播/达人对商品质量与售后"承担一切责任"的条款，应改回按角色分责（宣传真实性归主播，质量与售后归供货方）。
- `T4@newretail`：合作终止或提前解除后限期下线全部直播切片、图文素材与投流物料，停用并归还账号/店铺权限、删除留存数据，出具书面确认，并结清应付未付的佣金；**善后按固定顺序清算**——已投放费用 → 已售货品与售后退换 → 未结佣金 → 库存与物料 → 保证金退还；**终止不影响在途订单与存续条款**（保密、结算、知产、争议解决）。
- `Q1@newretail`：核验平台/直播服务机构资质（ICP 许可或备案、平台入驻资格）与商品品类所需的经营许可；达人与主播身份信息、代理权限与年龄合规留档备查。
- `E6@newretail`：达人与个人主播的报酬支付、发票取得与代扣代缴义务落实到书面；接单、收款、开票主体须一致。
- `D2@newretail`：主播、达人与店铺运营人员的个人信息（身份证、银行账户、手机号）按最小必要收集、加密存储、限定用途，不写入公开文案与直播画面；机构汇总数据须有合法性基础，合作终止后按约定期限删除。

## 行业资质
电商经营主体资质；食品/保健品类目另需许可；跨境电商需海关注册登记与相应模式手续；直播与平台业务按《互联网信息服务管理办法》办理许可或备案（以现行法规为准）。

## 标准话术（示例）
- "产品清单、供货价、建议零售价作为附件并盖章；排他授权附年度业绩前提，未达标可回收。"
- "以'建议零售价'表述，不强制转售价格。"
- "渠道供货价、零售指导价不得低于约定底线；违反价格体系按窜货处理并承担违约金。"
- "平台不得单方变更服务费、结算周期或规则；变更须提前 30 日书面通知，未接受的可无责终止。"
- "退货按七日无理由与平台规则执行；因商品质量或描述不符产生的运费由责任方承担。"
- "促销、赠品、返现方案须事先书面确认，费用如实入账，不得以任何形式账外返利。"
- "坑位费对应保底 GMV（或 ROI）人民币【 】元；未达标的按未完成比例退还坑位费，或经我方书面同意后延期补足场次。"
- "佣金以**实际结算并签收、且已过七日无理由退货期**的订单金额为基数计算；发生退货、退款或取消订单的，相应佣金自最近一期结算款中扣回。"
- "GMV 指合作商品在约定渠道的**已支付且未退款**的订单金额总和，不含运费，优惠成本按约定方式分摊；以平台后台数据为准，我方有权查阅原始订单明细或委托第三方核销。"
- "不得以任何方式虚构或篡改关注度、浏览量、点赞量与交易额，不得组织 NPC、水军刷屏或以虚假账号操纵评论；违反的按损害我方商誉处理，我方有权立即解除合同并追偿。"
- "达人/主播须保证已实际使用所推荐的商品或接受过相应服务；不得对其未使用过的商品作推荐、证明（《广告法》第 38 条）。"
- "凡涉及我方品牌账号、店铺后台与会员数据的，账号登记权益归我方；合作终止后 7 日内归还权限、移交运营资料并删除留存副本（T4）。"
- "代言人、达人违反法律法规、公序良俗，或发生其他重大负面事件（含行政处罚、刑事立案调查）的，我方有权单方解除合同、要求退还已付费用并下线全部物料。"
- "平台对保证金的扣罚须书面列明依据、金额与申辩渠道，单次扣罚不得超过保证金总额的 20%，累计不超过 50%（M1、P2）。"
- "直播口播与商品详情不得含绝对化用语、'全网最低价''史低'等无法举证的价格宣传，不得虚构原价或降价幅度。"
- "广告投放账户（含巨量千川、巨量引擎等）以我方名义注册并由我方实名；受托投放须事先书面确认预算、出价与投放计划，乙方应按日导出消耗明细供我方核对；合作终止后账户余额于 15 日内退还，账户及数据一并移交。"
- "达人不得要求粉丝站外成交或向站外导流；发现的站外成交订单不计入 GMV，且我方有权按约定标准扣除违约金。"
- "任何一方提前取消单场或取消合作的，须提前【 】日书面通知；窗口期外取消的，按已发生成本的书面凭证结算，并支付相当于坑位费【 】% 的违约金。"
- "本协议终止后【 】日内完成善后清算，顺序为：已投放费用 → 已售货品与售后退换 → 未结佣金 → 库存与物料 → 保证金退还；保密、结算与争议解决条款在终止后继续有效。"
- "发生不可抗力致合同目的不能实现的，任一方可解除合同；**不可抗力不免除双方就已发生部分已产生的付款义务**，善后依上款顺序清算。平台限流、规则重大变更或长期断供，双方应协商调整，协商不成时我方有权解除并按实际履行部分结算。"
- "因退货、退款、取消订单产生的佣金自最近一期结算款中扣回；争议期内我方有权暂缓结算，不构成违约。"
- "主播仅就其宣传内容的真实性负责；商品质量、货权与售后服务由供货方（经销商/品牌方）承担，本约定不因合作形式变更而改变。"
- "机构对其签约主播在合作期内的直播行为承担管理责任；机构与主播之间的用工性质及相应责任由机构依法自行承担。"
