# 医疗卫生行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
采购方（医院/医疗机构）／供货方（药品、耗材、器械）

## 必备条款焦点
1. 资质：药品经营许可证（GSP）、医疗器械经营许可/备案、批准文号/注册证、生产企业资质、**执业医师资格与执业注册（含主诊医师备案）**。
2. 两票制/票据：开票与随货同行单合规，票据链完整。
3. 质量与效期：质量标准、检验报告、到货剩余有效期下限、冷链。
4. 退货与召回：质量问题退换、召回/下架、效期临近处理。
5. 账期与回款：结算方式、账期、逾期责任（P1）。
6. 廉洁：反商业贿赂双向条款＋违约后果（H1）。
7. 集采/挂网合规：价格联动、补差机制。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 医疗器械（注册/备案） | 注册证/备案凭证 | 注册证随附、规格与型号一致（E、Q）、变更与延续 |
| 经营许可 | 经营许可/备案 | 经营范围与类别匹配、储运条件（冷链） |
| 高值/低值耗材 | 集采中选 | 两票制、**集采价与配送**、回款账期、UDI 追溯 |
| 医疗服务/医美 | 执业许可、**执业医师资格与执业注册、主诊医师备案** | 执业资质与**主诊医师**、知情同意、**医美广告合规**、不得由非卫生技术人员实施诊疗 |
| 检验检测 | CMA/CNAS | 报告效力与责任、样本与数据合规（D） |
| 设备采购与维保 | — | 验收/安装培训、维保范围与响应、备件 |
| SPD/供应链 | — | 院内物流与库存、结算与对账 |
| 不良事件/召回 | 监测义务 | 不良事件报告时限、召回配合与费用 |

> 通用：注册证/批件随附（E、Q）；UDI 追溯；集采与两票制；患者个人信息与知情同意（D、F15）；廉洁与反商业贿赂（H）。

## 推广与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 广审/广告 | 医疗广告须审查（《广告法》第 46 条、《医疗广告管理办法》）；器械/药品广告广审；医美广告不得承诺效果 |
| 学术推广/佣金 | 学术推广真实留痕、与销量脱钩；佣金/服务费/票折禁商业贿赂（《反不正当竞争法》第 8 条） |
| 两票制/集采 | 两票制票据流与货物流一致；集采中选价与配送、回款账期 |
| 器械代表 | 器械/医药代表合规（备案、不得承担销售任务） |
| 效期/追溯 | 效期与近效期、UDI 追溯、召回 |

## 高频风险 TOP
1. 质量/效期附件缺失（V1）★★★
2. 账期过长、无逾期违约责任（P1）★★★
3. 缺廉洁条款或单向（H1）★★
4. 两票制/票据链不合规 ★★
5. 退换货无边界、集采补差无界 ★★

## 对 core 的覆盖
- `H1@medical`：廉洁双向对等＋解除权＋违约金（反商业贿赂）。
- `V2@medical`：到货剩余有效期下限；质量随有效期。
- `P1@medical`：账期与逾期违约金（LPR×1.5，上限 LPR×4）。

## 行业资质
药品经营许可（GSP）、医疗器械经营许可/备案、注册证/批准文号、**执业医师资格与执业注册（含医美主诊医师备案；诊疗活动不得由非卫生技术人员实施）**（以现行法规为准）。

## 标准话术（示例）
- "供货方须提供药品经营许可证、注册证/批准文号及随货同行单据；票据链符合两票制。"
- "双方及人员不得行贿；违反的，对方有权解除合同并要求违约金及赔偿。"
- "注册证/备案凭证、生产/经营许可证随货提供，规格型号应与招标文件一致。"
- "集采中选品种按中选价与约定配送时限供货；逾期或断供承担违约金与替代差价。"
- "高值耗材须提供 UDI 追溯信息；发生不良事件供方应在 24 小时内报告并配合召回。"
- "合同签订与履行不得给予任何形式回扣；违反的按廉洁条款解除合同并追究责任。"
- "医疗服务应由具备执业医师资格并依法注册的人员实施，医美项目另须完成主诊医师备案；不得由非卫生技术人员从事诊疗活动。"
