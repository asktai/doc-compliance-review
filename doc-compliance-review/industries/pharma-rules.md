# 医药行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
申办者（临床试验）／供货方（药品、原料药）／采购方（原料、设备、服务）

## 必备条款焦点
1. 质量与资质：GMP/GSP、药品生产/经营许可证、批准文号、首营资料、检验报告、**执业药师配备与在岗（经营/零售环节）**。
2. 临床/CRO：经费口径与总包一致、里程碑付款、受试者损害先行赔付＋追偿（GCP2020第39条）、临床试验责任险、SUSAR 时限（致死/危及生命7日、其他15日）。
3. 数据与样本：数据/成果归申办者；生物样本/HGR 由申办者统一申报；PIPL 单独同意。
4. 召回与产品责任：召回/下架/销毁/媒体危机/行政处罚费用分担；产品责任险并列我方为附加被保险人。
5. IP：处方/工艺/质量标准/商标归我方（I4）。

## 产品类型细分（按品类审查要点）
| 品类 | 关键资质/批件 | 审查要点（含 core 引用） |
|---|---|---|
| 中药（中药材） | 产地/GAP、药材标准、检验报告 | 质量标准（ChP/部颁）与批号效期附件化（V1、V2）；毒性药材特殊管理；种植/收购合规。 |
| 中药饮片 | 生产/经营许可（含饮片范围）、炮制规范 | 国标/省标（地方标）炮制规范与检验方法；包装标签与保质期；毒性饮片专管；追溯码。 |
| 中成药 | 批准文号（国药准字Z…）、质量标准 | 处方药/OTC 标识；委托生产（MAH）与质量责任（I4、L3）；中药保护品种事宜。 |
| 配方颗粒 | 国标/省标（地方标）、生产企业资质与备案 | 医疗机构使用限制与渠道；医保支付与价格口径（P2、M1）。 |
| 破壁饮片/破壁颗粒 | 质量标准与检验方法（省标/备案） | 稳定性数据、包装与标识、宣称合规（不得疗效宣称）。 |
| 化药 | 批准文号（H…）、注册标准、GMP | 一致性评价/参比制剂；辅料包材关联审评；MAH 与委托生产；变更管理。 |
| 生物药 | 批签发（如适用）、GMP、冷链 | 温控记录与转运责任（V1、V3）；生物安全；变更与追溯。 |
| 原研药（进口） | 进口注册证/批件 | 专利链接与数据保护；参比制剂；进口分包装与批件随附。 |
| 处方药 | — | 凭处方销售/使用与审核留存；**不得向公众做广告**（《广告法》第 15 条）；说明书禁忌与警示。 |
| OTC / 非OTC | — | OTC 专有标识与甲/乙类销售渠道；广告须经审查（《广告法》第 46 条）；说明书与禁忌提示。 |

| 小包装饮片 | 生产/经营许可＋炮制规范 | 定量小包装标注（品名/规格/批号/效期/产地）、拆零与贮存、追溯码（V1、V2） |
| 养生汤（药膳/代煎/膏方） | 药食同源目录边界；食品经营/药品零售资质 | **属性界定**（食品 or 药品）、不得宣称疾病治疗功能、代煎加工服务责任与温控（V1、L3） |
| 养生堂/养生学院/养生研究院（大健康服务·培训·研究） | 相应经营/办学/科研资质 | 服务与培训内容边界、**宣传不得医疗宣称**（《广告法》《医疗广告管理办法》）、消费者权益、课程与配方 IP（I4）、科研合作成果归属（I4）、合作与加盟合规 |

## 推广与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 广审/广告 | 药品/器械广告须取得**广告审查批准文号（广审）**（《广告法》第 46 条）；处方药**不得向公众广告**（第 15 条）；不得含功效/安全性断言（第 16 条）。 |
| 疗效/功效宣称 | 不得宣称治愈率/有效率、不得与其他药品比较、不得利用患者或专家形象作证明（第 16 条）。 |
| 学术推广/佣金/票折 | 学术推广须真实、可留痕、与销量脱钩；佣金/服务费/票折不得变相商业贿赂（《反不正当竞争法》第 7 条）；服务商/代理商资质与合规承诺、反商业贿赂条款。 |
| 两票制 | 药品购销两票制，票据流与货物流一致；配送与结算合规。 |
| 效期/票折/终端 | 效期与近效期管理；票折/返利如实入账；电商/新零售/第三终端渠道价格与窜货管控。 |
| 医药代表 | 医药代表**备案**，不得承担销售任务、不得直接销售（《医药代表备案管理办法》）。 |

| 代加工/委托生产（OEM/MAH） | 委托方持有批件/资质；受托方生产许可与 GMP | 委托生产协议、**MAH 质量责任不转移**、批件与批准文号随附、工艺与标准附件化（V1、I4）、质量协议（放行/召回/责任划分）（L3） |
| 品牌授权（贴牌/商标许可） | 商标权属清晰 | 授权范围/期限/地域/渠道、**质量与合规责任归属**、标识与包装审核、备案与再许可禁止、侵权与赔偿（I1、I4） |

| 药食同源/食药同源（食药物质） | 按“既是食品又是中药材的物质目录”界定 | **属性界定**（食品 or 药品）、适用标准与许可、宣称边界、不得医疗宣称 |
| 道地/地道药材 | 地理标志/产地证明 | 产地与等级约定、质量标准（地方标）、检验报告、追溯（V1） |
| 原研/仿制药 | 原研：进口/注册批件；仿制：一致性评价 | 参比制剂、**一致性评价/生物等效性**证据、替代与变更、价格与医保 |
| 包装/标签 | 药品说明书和标签管理规定 | 标签内容与批准一致、专有标识、说明书随附、包材符合标准（V1、W4） |
| 农产品/农副产品（原料） | 农产品质量安全 | 承诺达标合格证、农药残留/重金属限量、产地与溯源（Q、V1） |

> 通用要点：批件/批准文号随货随件（E、Q）；批号与效期、质量标准与检验方法约定为附件（V1）；异议期按效期/保质期（`V2@pharma`）；召回/追溯/冷链责任与产品责任险。以上品类以 NMPA 现行法规与标准为准（《药品管理法》及配套办法、配方颗粒管理要求等），落锤前核验。

## 高频风险 TOP
1. 金额/付款/附件预算并存两套数值（W4、P4）★★★
2. 预付过高、付款早于交付（P3、P4）★★★
3. 受试者损害"全部责任"过宽、缺追偿与保险（L3）★★
4. 缺 HGR/个人信息合规（D4）★★
5. 质量/验收标准附件缺失（V1）★★★

## 对 core 的覆盖
- `V2@pharma`：药品/器械外观异议期 15–30 日；质量随有效期/保质期。
- `I4@pharma`：处方/工艺/商标归我方并保密。
- `D4@pharma`：受试者个人信息单独同意；HGR 统一申报。

## 行业资质
GMP、药品生产/经营许可证（GSP）、医疗器械备案/注册＋经营许可、GLP/GCP 相关、**执业药师配备与在岗履职**（药品经营/零售环节：处方须经执业药师审核后方可调配销售，不得以其他人员替代或"挂靠"）（以现行法规为准）。

## 标准话术（示例）
- "质量标准、检验报告、处方与工艺文件应作为合同附件并签章，未附不得签署。"
- "受试者损害由申办者依 GCP 先行承担，保留对机构/研究者/CRO 过错部分全额追偿。"
- "批件（注册证/批准文号）、质量标准与检验报告随货随件；未附不得入库。"
- "变更生产场地、工艺、包材或标签的，应提前 30 日书面通知并经我方书面同意。"
- "涉及委托生产的，受托方应持相应生产许可与 GMP 证书，质量责任由委托方（MAH）承担。"
- "药品经营/零售环节应配备执业药师并在岗履职，处方须经执业药师审核后方可调配销售；不得由非执业药师代行审核，不得证书挂靠。"
- "学术推广费用与服务费如实入账、与销量脱钩；任何形式的账外返利、票折视为违约。"
