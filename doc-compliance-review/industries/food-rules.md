# 食品行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
采购方／供货方（含委托加工）

## 必备条款焦点
1. 资质：SC 食品生产许可、检验报告、批次合格证明、进口检验检疫。
2. 质量与安全：食品安全标准、配料/标签合规（GB 7718）、留样与稳定性。
3. 效期：到货剩余保质期下限（如≥总保质期 2/3）；临期界定与处理。
4. 冷链：温控记录、断链责任、验收温度。
5. 召回与惩罚性赔偿：召回/下架/销毁费用分担；惩罚性赔偿须**现金赔付**，不得以货抵充。
6. 委托加工：受托方资质、现场监督权、记录保存（保质期满后≥6个月）。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 预包装食品 | SC 生产许可 | 产品标准（GB）与检验方法附件化（V1）、标签（GB 7718/28050）（W4） |
| 散装/生鲜冷链食品 | 食品经营许可 | 冷链温控与验收记录（V3）、保质期与销毁、损耗分担 |
| 保健食品 | 注册/备案 | 功能宣称合规、**广告须审查**（《广告法》第 46 条）、不得宣称治疗功能 |
| 婴幼儿配方/特医食品 | 产品配方注册 | 注册证随附（E、Q）、标签与宣称合规、召回报备 |
| 食品添加剂 | SC（含添加剂品种） | 使用范围与限量（GB 2760）、标识与安全数据 |
| 食品相关产品/包材 | 生产许可（如适用） | 符合食品安全标准（GB 4806 系列）、迁移限量 |
| 进口食品 | 进口商备案、检验检疫 | 中文标签、入境货物检验检疫证明（E、Q） |
| 餐饮/中央厨房 | 食品经营许可 | 加工规范、留样与追溯、配送温控 |
| 代加工（OEM） | 委托方资质与责任 | 委托生产协议、配方与工艺保密（C、I4）、质量责任划分（L3） |

| 代用茶/含茶制品 | SC（茶叶及相关制品） | 配料与标签（GB 7718）、**不得宣称功效/保健功能**、广告审查（《广告法》第 17、46 条） |
| 茶饮（现制饮品） | 食品经营许可 | 原料溯源与保质期、现制标签与添加剂使用（GB 2760）、冷链与卫生 |
| 广告审查/功效/推广 | — | **食品广告不得涉及疾病预防、治疗功能**（《广告法》第 17 条）；非保健食品不得宣称保健功能；保健食品广告须审查（第 46 条）；推广用语与赠品合规 |

## 推广与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 广审/广告 | 保健食品广告须审查（《广告法》第 46 条）；食品广告不得涉及疾病预防、治疗功能（第 17 条）、不得宣称保健功能。 |
| 功效/疗效/推广 | 禁用“治疗/疗效/根治”等表述；功效宣称须有依据；推广用语与赠品合规（《反不正当竞争法》）。 |
| 渠道/电商/新零售/终端 | 渠道价格体系与窜货管控；平台信息披露义务；票折/返利如实入账。 |
| 效期 | 效期与近效期管理、临期食品标识与处理。 |
| 佣金/服务商/代理商 | 服务商/代理商资质与合规；佣金与促销费用如实入账、禁止商业贿赂。 |

| 品牌授权（贴牌/商标许可） | 商标权属清晰 | 授权范围/期限/地域/渠道、质量与合规责任、标签与包装审核（GB 7718）、备案与再许可、侵权赔偿（I1、I4） |

| 食用农产品/农副产品 | 农产品质量安全法、承诺达标合格证 | 产地与溯源、农残/重金属限量、贮藏运输（V3） |
| 药食同源/食药同源 | 食药物质目录 | 属性与许可、宣称边界、不得医疗/功效宣称 |
| 调味料 | SC（调味品） | 产品标准、添加剂（GB 2760）、标签与保质期 |

> 通用：SC/资质随附（E、Q）；标准与检验方法附件化（V1）；异议期按保质期（`V2@food`）；召回与追溯（《食品安全法》）。

## 高频风险 TOP
1. 质量/检验报告未附件（V1）★★★
2. 未约定到货效期下限（V2）★★
3. 冷链断链责任不清 ★★
4. 惩罚性赔偿以货抵充（L3、L5）★★★
5. 全额预付（P3）★★★

## 对 core 的覆盖
- `V2@food`：外观/数量 7 日；质量随保质期。
- `L3@food`：惩罚性赔偿（《食品安全法》第148条）须以现金赔付并保留追偿。

## 行业资质
SC 生产许可；进口食品检验检疫；预包装食品标签合规（以现行法规为准）。

## 标准话术（示例）
- "质量标准及检验报告作为附件；到货剩余保质期不低于总保质期的 2/3。"
- "涉惩罚性赔偿的，应由责任方以现金赔付，不得以产品抵充。"
- "感官/理化/微生物指标按 GB 执行，检验报告随货；留样不少于保质期届满后 6 个月。"
- "临期食品（剩余保质期不足 1/3）应明示并按约定折价或退货，不得以次充好。"
- "涉保健食品、婴配、特医的宣称须与注册/备案内容一致，广告发布前经我方书面审查。"
- "原料/包材变更须提前 30 日书面通知并经我方确认，未经确认的变更由供方承担全部责任。"
