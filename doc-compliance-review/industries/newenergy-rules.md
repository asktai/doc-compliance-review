# 新能源行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
发包方（业主）／承包方（EPC/安装/设备）

## 必备条款焦点
1. 资质：承装（修、试）电力设施许可、施工资质、安全生产许可证（Q3）。
2. 设计—设备—施工—并网：范围界定、接口界面、并网与验收标准。
3. 发电量保证：发电量/效率保证与未达标补偿（L4）。
4. 质保与运维：质保期、O&M 运维服务、备件与响应时限。
5. 安全责任与保险：人身/第三方安全、工程险/责任险。
6. 工期与不可抗力：工期节点、顺延与共同承压。
7. 造价与变更：工程量、变更签证、结算方式。
8. 分包限制：未经同意不得转分包，分包方行为承包方全责。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 光伏（组件/逆变器） | 产品认证 | 质保与**功率衰减率**（首年/线性）、效率保证与考核、到货验收（V1） |
| EPC/施工 | 施工资质＋安许 | 工期与并网节点、总包/分包责任、隐蔽工程验收（V3） |
| 电站运维 | 运维资质 | 运维 SLA（可用率/响应）、发电量考核与赔付 |
| 储能（电芯/PCS/系统） | 型式试验/认证 | 循环寿命与容量保证、安全与消防、质保与更换 |
| 风电 | 设备认证 | 可利用率保证、吊装安全责任、质保期 |
| 充电桩 | 生产/运营资质 | 设备质保、平台服务与结算、场地责任 |
| 售电/绿电交易 | 售电资质 | 电价机制、偏差考核、结算周期（P2） |
| 碳资产（绿证/CCER） | 登记 | 权益归属与转让、登记与交割 |

> 通用：资质（承装（修、试）电力设施许可、Q3）＋施工资质＋安许；发电量/衰减量保证与保险；补贴与结算；并网与电价。

## 供应链与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 资质核验 | 承装（修、试）电力设施许可＋施工资质＋安许（Q3）；设计/监理相应资质 |
| EPC/分包 | 总包责任不因分包转移、分包审批与转包禁止、隐蔽工程验收（V3） |
| 设备供应 | 型式试验/认证、质保与**衰减/可用率保证**、备件与售后年限（V1、L3） |
| 并网与电价 | 并网节点与验收、电价机制与补贴政策、结算周期（P2） |
| 碳资产 | 绿证/CCER 权属与转让、登记与交割、数据真实性 |
| 保险与保函 | 履约/质量保函、发电量损失险、财产与人身险责任划分 |

## 高频风险 TOP
1. 资质不足/无安许（Q3）★★★
2. 并网/验收标准不清、发电量保证无罚则（V3、L4）★★
3. 安全责任与保险缺失 ★★★
4. 工期/不可抗力单方归责 ★★
5. 分包失控、责任主体不清 ★★

## 对 core 的覆盖
- `Q3@newenergy`：电力施工/安装资质等级与安许核验。
- `L3@newenergy`：安全责任对外先行赔付、对内按过错追偿。
- `L4@newenergy`：发电量/效率未达标的补偿机制。

## 行业资质
承装（修、试）电力设施许可证；电力工程施工总承包/专业承包资质；安全生产许可证（以现行法规为准）。

## 标准话术（示例）
- "承包方须具备覆盖本工程的资质等级与安全生产许可证，并提供复印件备案。"
- "发电量未达保证值的，按差额电量折算补偿。"
- "组件首年衰减≤2%、逐年≤0.55%，25 年输出功率不低于标称的 80%；未达标按差额赔付。"
- "可用率≥98%；未达标的按运维费扣减，连续两个月低于 95% 我方有权终止运维合同。"
- "并网节点与电价结算以电网公司批复为准；因供方原因并网延期按日计违约金。"
- "EPC 分包须经我方书面同意，总包方对分包工程质量与安全承担连带责任。"
