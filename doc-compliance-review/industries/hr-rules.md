# 人力资源（HR）行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
用工单位（采购派遣/外包）／用人单位（直接雇佣）／人力资源服务方

## 必备条款焦点
1. 用工性质与"三性"（临时性/辅助性/替代性）；**派遣用工比例不超过 10%**（《劳动合同法》66条、《劳务派遣暂行规定》）。
2. 同工同酬；社保公积金依法足额缴纳；加班费不得以"包干价"掩盖（《劳动法》41、44条）。
3. **工伤与连带责任**：用工单位与派遣单位承担连带赔偿责任（《劳动合同法》92条）；工伤/用工保险。
4. 退回机制与违法退回的后果。
5. 员工个人信息（身份证/健康/工资）依《个人信息保护法》最小必要。
6. 保密与竞业限制（《劳动合同法》23、24条；须支付竞业补偿金）。
7. 解除与经济补偿（《劳动合同法》47条，N/N+1）。
8. 廉洁与用工合规（反商业贿赂；禁止童工/强迫劳动）。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 劳动合同 | — | 必备条款（《劳动合同法》第 17 条）、**试用期上限**（第 19 条）、无固定期限情形 |
| 劳务派遣 | 经营许可 | **三性**（临时/辅助/替代）＋**用工比例≤10%**、同工同酬、退回机制 |
| 外包（岗位/业务） | — | **“假外包真派遣”风险**、管理与指挥边界、责任划分（L3） |
| 灵活用工/众包 | 平台资质 | 用工关系定性、税务与发票、工伤与安全保障 |
| 招聘服务（RPO） | 人力资源服务许可 | 服务标准与保证期、候选人信息合规（D） |
| 薪酬代发/社保代缴 | 资质 | 资金安全、滞纳金与罚款责任、数据保密（C、D） |
| 竞业限制/保密 | — | **补偿标准（月均工资 30% 或约定）**、期限≤2 年、范围合理 |
| 员工借调/委派 | — | 工伤责任、社保缴纳、管理权与责任 |

> 通用：民主程序与公示（F12）、社保与工伤（Q）、个人信息（D）、廉洁（H）、经济补偿与赔偿金计算（L）。

## 用工与外包合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 派遣 | 三性（临时/辅助/替代）＋比例≤10%、同工同酬、退回与连带责任 |
| 外包 | “假外包真派遣”界定、管理与指挥边界、用工责任划分（L3） |
| 灵活用工 | 关系定性与税务处理、平台资质、工伤与安全保障 |
| 社保/工伤 | 足额缴纳与滞纳金风险、工伤责任与商业保险、代缴合规（Q） |
| 竞业/保密 | 补偿标准（月均工资 30% 或约定）、期限≤2 年、范围合理（C） |
| 制度与公示 | 民主程序与公示（F12）、员工个人信息与背景调查合规（D） |

## 高频风险 TOP
1. 派遣突破"三性/10% 比例"（Q2）★★★
2. 综合包干价未拆分加班费（M/P）★★
3. 工伤/用工责任不明、无保险（L3）★★★
4. 缺员工个人信息合规（D1）★★
5. 退回/解除无客观标准（T3）★★

## 对 core 的覆盖
- `Q2@hr`：劳务派遣经营许可、人力资源服务许可核验。
- `L3@hr`：工伤/用工连带责任，对外先行赔付＋对内按过错追偿。
- `D1@hr`：员工个人信息最小必要并取得同意。
- `T3@hr`：退回/解除须客观标准。

## 行业资质
劳务派遣经营许可；人力资源服务许可；职业中介许可（以现行法规为准）。

## 标准话术（示例）
- "派遣岗位须符合'三性'，用工比例不超过 10%；同工同酬、社保足额缴纳。"
- "用工单位与派遣单位对劳动者损害承担连带责任；甲方先行赔付后就乙方过错部分全额追偿。"
- "派遣用工仅限临时性、辅助性、替代性岗位，用工数量不超过用工总量的 10%。"
- "竞业限制补偿不低于离职前十二个月平均工资的 30% 且不低于当地最低工资，期限不超过 2 年。"
- "外包服务不得约定对我方员工的直接指挥管理，以避免被认定为事实用工。"
- "员工个人信息处理限于人力资源管理目的，遵循最小必要并履行告知同意。"
