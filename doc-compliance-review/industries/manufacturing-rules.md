# 制造业行业包（仅增量/覆盖，引用 core 规则 ID）

## 常见我方角色
采购方（委托加工/设备采购）／供货方（OEM/零部件）

## 必备条款焦点
1. 技术要件：技术规格书/图纸/样品/技术协议**附件化并签章**；变更控制。
2. 质量与验收：来料/制程/成品检验、抽样标准、不合格处理与返工。
3. 模具与工装：**模具/工装权属归我方**，保管、维护、返还。
4. 交付：交期、包装、运输与风险转移时点。
5. 质保：质保期与售后响应、备件供应。
6. 停工/订单变更/损耗：超耗与损耗承担（合理损耗由受托方承担）。
7. IP：图纸/工艺/技术资料归我方（I4）。

## 业务细分（按业务/品类审查要点）
| 业务/品类 | 关键资质/依据 | 审查要点（core 引用） |
|---|---|---|
| 采销（原材料/设备） | 供应商资质 | 技术规格与图纸附件化（V1）、验收（到货/试运行/终验）、质保 |
| 委外加工（OEM/ODM） | 受托方资质 | 技术文件与工艺保密（C、I4）、质量责任与不良率罚则（L3） |
| 模具/工装 | 权属约定 | 模具权属与保管、验收与维护、返还与销毁 |
| 技术协议 | — | 图纸/标准/公差、变更流程（ECN）、变更责任 |
| 质量三包 | — | 三包期限与响应时限、备件供应年限 |
| 来料加工 | 海关（如保税） | 料件权属与损耗、边角料处理 |
| 设备安装调试 | 安装资质 | 调试验收标准、培训与交付文档、安全责任 |
| 产能/交期 | — | 产能保证与违约金、产能调整机制 |

> 通用：技术标准附件化（V1）、隐蔽瑕疵与质保（V2、L）、工艺与图纸 IP（I4）、环保与危险品合规（Q）。

## 供应链与渠道合规（要点）
| 触发情形 | 审查要点 |
|---|---|
| 供应商/外协 | 准入资质与审核、双源与断供风险、转包/外协管控与质量责任（Q、L3） |
| 经销/代理 | 授权范围与区域、窜货与价格体系、经销政策变更的公平性 |
| 采购廉洁 | 回扣/账外折扣禁止、廉洁条款与审计权（H）、关联交易披露 |
| 价格与调价 | 原材料价格联动机制、调价触发与生效、汇率与运费分担（P2、W4） |
| 质量索赔/退货 | 三包与索赔时效、退货/换货/返修的责任与费用、不良率罚则（V2、L3） |
| 物流与保险 | 交付风险转移时点、运输保险、包装与标识合规 |

## 高频风险 TOP
1. 技术规格/图纸附件缺失（V1）★★★
2. 模具权属不明、无返还约定 ★★
3. 验收标准缺失、不合格处理不明（V3）★★
4. 付款与验收脱钩、全额预付（P3）★★★
5. 超耗/损耗承担方约定相反（P6 方向性）★★

## 对 core 的覆盖
- `I4@manufacturing`：图纸/工艺/技术资料归我方并保密。
- `P3@manufacturing`：付款与验收挂钩，留存质保金。

## 行业资质
特种设备制造/安装需相应许可；涉危化/安全另需资质（以现行法规为准）。

## 标准话术（示例）
- "技术规格书、图纸、样品作为附件并签章；模具归委托方所有，受托方妥善保管并应要求返还。"
- "技术文件（图纸、标准、公差、BOM）作为附件签署，变更经 ECN 书面确认后方可实施。"
- "关键物料/外协件须自我方确认的供方目录采购，未列入的按不合格品处理。"
- "试运行与终验标准、期限及整改复验规则明确；验收不合格的返工费用由供方承担。"
- "质保期内响应时间（到场≤48 小时）与备件供应年限（不少于 5 年）明确约定。"
