# 法条与名称核验清单（落锤前必核）

> **用途**：技能输出的每条法律依据、法院名称、标准号、示范文本与链接，**出具前须逐项核验"现行有效"**。
> 本清单是**核验工具**（打勾表），不是规则库；规则见 `01-general-risk-rules.md`。
> **原则**：核验不了的，在报告中标注"待核验"，**禁止编造条号或名称**。
> **元数据**：版本 **V3.7.0** ｜ **生效日 2026-09-21** ｜ **最近修订 2026-09-22**

---

## 一、核验三道关

| 关卡 | 核验内容 | 不通过的处理 |
|---|---|---|
| 1. 条号存在性 | 条号是否真实存在、是否与规则主张一致 | 改引正确条号；无法确认则删引，改注"实务惯例（参考性）" |
| 2. 现行有效性 | 是否被修订、废止或被新法吸收（特别注意司法解释同步更新） | 换用现行条文；旧条号注明"已被＿＿＿取代" |
| 3. 名称/表述准确性 | 法院全称、标准号、示范文本名称、机构名称准确无误 | 核对后更正；法院名称须真实存在且名称规范 |

## 三、易失效与已修订速查（援引前先看这里）

| 情形 | 说明 | 处理 |
|---|---|---|
| 《民法典》施行后的旧法 | 《合同法》《物权法》《担保法》《侵权责任法》《民法总则》《民法通则》等九部法已随《民法典》施行**同时废止** | **不得再引旧法条号**；改引《民法典》对应条文并按现行版本核验 |
| 担保规则 | 原《担保法》及其解释已废止，现行为《民法典》担保规则＋担保制度司法解释 | 涉保证方式、公司对外担保时按现行解释核验 |
| "纪要"类文件 | 《全国法院民商事审判工作会议纪要》等**既非法律、也非司法解释** | 只能表述为"裁判观点（参考性）"，**不得写成"依据《…》第…条"** |
| 《民事诉讼法》历次修正 | 协议管辖、送达、小额诉讼等条号随修正变动 | 援引前核现行条号；不确定则写"依现行《民事诉讼法》关于协议管辖的规定" |
| 《公司法》2023 修订 | 2024-07-01 施行，注册资本认缴、股东出资、决议效力等条号体系变动大 | 涉公司类文档**一律核验后引用**，不得沿用旧条号 |
| 《反垄断法》2022 修正 | 条文序号调整 | 同上 |
| 行政与税务类规定 | 发票管理、行政处罚、行政复议等近年均有修订 | 标注施行/修正年份后引用 |
| 行业强制标准 | GMP/GSP、GB 等标准号**含年代号**，会被新版替代 | 核验是否为现行版本（连年代号一并核对） |
| 地方法规与司法文件 | 效力层级低、更新频繁、适用范围受限 | 注明效力层级与适用范围，**不作上位法引用** |

## 四、引用格式与禁用写法

- **规范格式**：《全称》第 X 条第 X 款第 X 项（可括注施行/修正年份）；司法解释写《最高人民法院关于……的解释》第 X 条。
- **禁用写法**：1. 只写条号不写法名（"根据第 X 条"）；2. 自造或沿用已废止的法名（如再引"《合同法》第 X 条"）；3. 把纪要、答复、指导意见写成"第 X 条"；4. 引用已废止法或被替代的旧条号；5. 以"相关法律规定"含糊带过而不给出可核验的出处。
- **不确定时**：写"实务惯例／裁判观点（参考性）"并说明理由，或显式标注"待核验"。**禁止为凑齐依据而编造条号或名称。**
