# 模板库说明（内置示范件）

本目录是技能**内置模板库**，随包分发、只读。每份 `*.tpl.md` 的**首行**是版本留痕
`<!-- tpl: 名称 | ver: X.Y.Z | date: YYYY-MM-DD | 变更: … -->`，其后即模板正文。

## 三处真源，别在别处另写一份

| 物 | 真源 | 谁生成 |
|---|---|---|
| 模板本体 | `templates/*.tpl.md` 首行留痕＋正文 | 人工／转模板流程 |
| 模板清单 | `templates/模板清单.md` | `tpl-engine.py manifest templates/ --out …` |
| 正文指纹基线 | `templates/_tpl-baseline.json` | `tpl-engine.py baseline templates/ --update` |

`check.py` 的 `check_template_library()` 会逐项比对三者：
**改了模板正文却不换版本号**（或换了版本号正文没动）都当场报错，
清单与实扫不一致也报错——这三处承诺由此变成机械判据，不靠人记得同步。

## 怎么用

```
python scripts/tpl-engine.py use templates/设备采购合同.tpl.md \
    --value 甲方全称="某某科技有限公司" --value 设备名称="XX-2000 型" \
    --value 数量=10 --value 合同金额="人民币壹佰万元整（¥1,000,000.00）" \
    --value 交付期限="15 个工作日" --switch 有第三方担保=0 --out 输出/采购合同草案.md
```

`use` 出的是**填实后的具体合同草案**；`render` 出的是**保留 `{{占位符}}` 的模板版**，
两者语义相反，别混（详见 `scripts/tpl-engine.py` 开头）。

## 谁的模板放哪

- **内置示范库**（本目录）：随技能包走，只读；升级时由发布链重建，故**不要**把
  自己沉淀的模板放这里——下次升级会被覆盖。
- **使用者自己的模板**：落在工作区输出目录，由转模板／撰写模板出件时一并保存。
  入库是**使用者动作**，与 `legal-lookup.py`「抓到的条文不写回、入库是人工动作」同口径。

## 红线

内置示范件的条款**仅示意占位符与条件段写法**，不构成法律意见；
套用前须经执业律师复核，并按本次交易补齐必备条款（见 `SKILL.md` 第五节 B 组）。
