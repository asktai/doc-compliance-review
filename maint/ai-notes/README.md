# AI 对话与学习参考资料（开发侧 · 不进技能包）

> 本目录属**开发侧**，**不进技能包、不随分发包外流**（铁律第 7 条）。

## 这里放什么

**给 AI 看、不是给使用者看**的资料：

- 会话里的**解释、讨论过程、决策理由**（第 8 条要求"不写进 SKILL.md"的那些）
- 供 AI **学习参考、理解背景**的资料（行业背景、术语解释、参考案例）
- AI 产出的**分析草稿**（尚未定稿、仅供讨论）

## 这里不放什么

| 内容 | 该去哪 |
|---|---|
| 已定稿的**决策记录**（正式回执） | `maint/DEVLOG.md` |
| 面向交付的**版本沿革** | `dev/CHANGELOG.md` |
| **测试数据**（临时／验证用） | `maint/test-data/` |
| **出题素材、草稿** | `maint/scratch/` |
| 使用者**真正要用**的内容 | 技能目录（`dev/doc-compliance-review/`） |

## 为什么要有这个目录

此前铁律只规定"不进的叫开发侧"，**没说该放哪**——于是资料容易被塞进技能目录
（看起来"就放在项目里"），只能靠出包时白名单丢弃兜住，且丢弃是**静默的**。
给资料一个**明确的去处**，就不会往技能目录里塞——这是**从根上解决**，
而不是靠出包时拦截。

**判据**：这份东西是**给使用者用的**，还是**给 AI／我们自己用的**？
后者一律放本目录。
