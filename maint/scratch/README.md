# 草稿与出题素材（开发侧 · 不进技能包）

> 本目录属**开发侧**，**不进技能包、不随分发包外流**（铁律第 9 条）。

## 这里放什么

**未定稿的、探索性的**东西：

- **出题素材**（给自检样本出题用的原始文档、规则清单）
- 改造前的**方案草案**（动手前的设计稿）
- 一次性**脚本草稿**（跑完就丢的临时工具）
- 试验性**改造脚本**（如批量重命名、编号映射，用毕留档）

## 这里不放什么

| 内容 | 该去哪 |
|---|---|
| **已定稿并长期使用**的工具脚本 | `maint/tools/` |
| **已定稿的方案** | `maint/plans/` |
| 决策记录 | `maint/DEVLOG.md` |
| AI 学习参考资料 | `maint/ai-notes/` |
| 测试数据 | `maint/test-data/` |

## 与 `maint/tools/` 的区别

| | `maint/scratch/`（本目录） | `maint/tools/` |
|---|---|---|
| **状态** | 草稿、一次性 | **定稿、长期维护** |
| **是否受守卫管** | 否 | **是**（如 `check-dev-rules.py` 有冒烟覆盖） |
| **是否进 git** | 是（留档） | 是 |
| **稳定度** | 随时可删 | 改动须走流程 |

**判据**：这东西**还在一稿一稿改**吗？是 → 放这里；**已经定了、以后还要用** → 放 `tools/`。
