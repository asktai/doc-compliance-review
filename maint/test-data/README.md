# 测试数据与验证资料（开发侧 · 不进技能包）

> 本目录属**开发侧**，**不进技能包、不随分发包外流**（铁律第 7 条）。

## 这里放什么

**为了验证、测试而准备的资料**——用完即弃或仅本机有效：

- 临时构造的**测试合同／测试文档**（验证某条规则能不能命中）
- 复现某个 bug 用的**最小样本**
- 从真实文档改写来的**脱敏样例**（仅本地验证用）
- 验证过程中的**中间产物**（截图、日志、比对结果）

## 这里不放什么

| 内容 | 该去哪 |
|---|---|
| **必须随包**的自检样本（使用者跑冒烟要用） | 技能目录 `doc-compliance-review/samples/`，**且须登记在准入清单** |
| AI 学习参考资料 | `maint/ai-notes/` |
| 出题素材、草稿 | `maint/scratch/` |
| 正式测试报告 | `maint/DEVLOG.md`（以记录形式） |

## 与技能目录 `samples/` 的区别（**关键，别混**）

两者都是"测试用"，但**受众不同**，管理方式也完全不同：

| | `maint/test-data/`（本目录） | `doc-compliance-review/samples/` |
|---|---|---|
| **受众** | 只有我们自己（开发时验证） | **使用者**（他跑冒烟要用） |
| **是否随包** | **否** | **是**（但须**逐条许可登记**） |
| **管理方式** | 自由放置 | **准入制**：默认拒绝，逐条许可 + 写明理由 |
| **判据** | 使用者**不需要** | 使用者**需要** |

**一句话**：使用者需要 → 进技能目录并登记；只有我们需要 → 放这里。
